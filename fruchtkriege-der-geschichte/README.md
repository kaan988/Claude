# Fruchtkriege der Geschichte 🍓⚔️🍉

## Schnellstart (Reihenfolge)

1. **Figuren:** Character Sheets → Hero-Bilder → als Higgsfield-Elements speichern (`02`)
2. **Startbilder** für alle Szenen in Nano Banana Pro (`03`)
3. **Stimmen** mit Eleven v4 erzeugen (`01`, Abschnitt 4)
4. **Animatik:** Standbilder + Ton in CapCut legen und Timing prüfen, das kostet 0 Credits (`05`)
5. **Videos** mit Kling 3.0 Pro aus den geprüften Startbildern (`03`)
6. **Karten** im Schnittprogramm bauen (`04`)
7. **Schnitt**, Untertitel (`untertitel-de.srt`), Musik, Export (`05`)
8. **Faktencheck** und Abnahme-Checkliste, dann hochladen (`06`, `05`)
